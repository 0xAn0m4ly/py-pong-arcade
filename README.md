# py-pong-arcade

This is my version of Pong, the famous arcade game from 1972, is written in Python and uses the pygame library that hadles
most of the technical structures of the game like the window and the main game loop, apart from it the entire game is
custom and can be easily modified.
The ball and the player's racket constantly increase their speed, the computer's racket is basically invincible so the game's
goal is to get the highest number of bounces. The game also provides the record score that erases every time the game is closed.

---

### What you get in the repository
* the main python file
* 3 audio files for sounds effects
* requirements.txt for downloading the library
* README text file

---

### Requirements

* **Python 3.x** installed on your system.
* **"pygame" library**: you can easily download it by cloning or
    downloading the **"requirements.txt"** file and by typing in the cmd line:
  ```bash
   pip install -r requirements.txt
  ```


---

### Installation & Execution

There is no complex setup. Just download the game and run it directly from your terminal or text editor.

1. **Download the script** (or clone the repository):
   ```bash
   git clone https://github.com/0xAn0m4ly/py-pong-arcade
   cd YOUR-REPO-NAME
   ```

2. **Run the program**:
   ```bash
   py pong.py
   ```

---

### ⚙️ How It Works
Start the game by clicking on the button at the start, then use the up and low arrow or the W and S keys to move
the player's racket. **Have fun!!!**
